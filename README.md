"# AI-Powered Personalized Learning Assistant

This is an AI-powered learning assistant for Python basics, aligned with SDG 4 – Quality Education.

## Features

- Interactive quiz on Python basics
- Rule-based chatbot with AI integration for advanced queries
- Personalized feedback based on quiz performance

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Set up OpenAI API key:
   - Get an API key from [OpenAI](https://platform.openai.com/api-keys)
   - Set the environment variable:
     ```
     export OPENAI_API_KEY='your-api-key-here'
     ```
     On Windows:
     ```
     set OPENAI_API_KEY=your-api-key-here
     ```

3. Run the program:
   ```
   python project.py
   ```

## Usage

- Take the quiz to test your knowledge
- Ask the chatbot questions about Python
- Type 'exit' to quit the chatbot

## Requirements

- Python 3.7+
- OpenAI API key"
